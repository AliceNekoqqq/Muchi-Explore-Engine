# Muchi Explore Engine v1.1.0

暮迟市现场探索引擎，独立于地图和 MR-87 收音机仓库。

## v1.1 核心变化

- 新增“现场行动轮”：一次正文叙事间隔内最多使用 3 点行动窗口，关闭/重开界面不会恢复。
- 搜索深度按“新增深度”消耗行动点：未搜索→快速=1，未搜索→仔细=2，未搜索→彻底=3；已经快速后再升到仔细只再消耗1点。
- 行动窗口耗尽、现场威胁逼近、或沈挽昼抑制窗口耗尽时，本轮锁定；必须先回正文推进一轮剧情，下一轮才能继续。
- 发作前兆/抑制窗口偏低时，行动上限会收紧为2；半狂暴、狂暴、深度异化或理智过低时禁止安静搜刮。
- 新增累计耗时、暴露风险和本轮搜索记录；“结束本轮并写入剧情”会一次性把整个行动轮写入输入框。
- 即时探索按钮、选中区域和收取按钮的视觉层级加强，手机版不再像低对比度文字链接。

## 数据归属

探索状态仍保存在当前聊天的 MVU `stat_data.地图.探索系统` 中，不使用 localStorage 保存世界进度。

`地图.探索系统.行动轮` 是 v1.1 新增字段。旧 v1.0 存档会在首次运行时自动补齐默认结构。

## 与其他模块的边界

- 地图：只负责地点展示、探索进度和入口。
- 探索引擎：负责子区域、行动轮、搜索深度、掉落、防重Roll、时间推进与即时UI。
- MVU：保存世界事实。
- 正文模型：只负责把脚本已经结算的事实演成剧情。
